# 制作道具与料理补全 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 新增约 30 件高频可制作道具、补齐配方材料链，并把烹饪锅料理从 30 道扩充到不少于 50 道，完成版本文案、图标、测试和 GitHub Pages 发布。

**Architecture:** 沿用现有 `WikiEntry` 单一数据模型。新增制作道具放入独立的 `crafting-expanded.ts`，配方依赖材料放入 `materials-expanded.ts`，新增料理放入 `dishes-expanded.ts`；三个文件在 `app/data/wiki/index.ts` 聚合，现有详情页、搜索、筛选和静态路由无需建立第二套实现。所有内部材料链接在单元测试中解析，图片继续由同步脚本生成来源清单并校验 SHA-256。

**Tech Stack:** Nuxt 3、Vue 3、TypeScript、Vitest、Nuxt Content、Node.js 图片同步脚本、GitHub Actions / GitHub Pages。

---
