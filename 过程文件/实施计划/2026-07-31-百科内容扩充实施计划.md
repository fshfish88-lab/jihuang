# 火堆边百科内容扩充 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 为《饥荒联机版》建立约 130 个带正确图标、制作/获取说明和完整锅配方的核心百科，并以档案速查型页面发布。

**Architecture:** 将百科结构化数据从现有通用内容注册表中拆出，按资源装备、建筑、料理、生物和探索五类维护；Markdown 只保留长篇攻略。百科详情页直接读取结构化数据并组合制作、获取、料理和来源组件，构建脚本负责强制校验。

**Tech Stack:** Nuxt 3、Vue 3、TypeScript、Nuxt Content、Vitest、Node.js、GitHub Actions、GitHub Pages

---

## 文件结构

- `app/types/wiki.ts`：百科条目、制作配方、获取途径和料理规则类型。
- `app/data/wiki/materials.ts`：资源、基础食材和常用材料。
- `app/data/wiki/equipment.ts`：工具、武器、护甲和功能装备。
- `app/data/wiki/structures.ts`：科技、照明、储藏和生产建筑。
- `app/data/wiki/dishes.ts`：30 道常用锅料理及四格示例。
- `app/data/wiki/creatures.ts`：常见生物和资源点。
- `app/data/wiki/exploration.ts`：季节、航海、洞穴和遗迹关键物品。
- `app/data/wiki/index.ts`：合并、查找、分类和转换搜索元数据。
- `app/components/wiki/ItemIcon.vue`：显示独立图标。
- `app/components/wiki/WikiFactsPanel.vue`：显示核心数值。
- `app/components/wiki/CraftingRecipe.vue`：显示制作材料、科技和产量。
- `app/components/wiki/AcquisitionList.vue`：显示分组获取途径。
- `app/components/wiki/DishRecipePanel.vue`：显示四格配方和料理规则。
- `app/components/wiki/SourceAttribution.vue`：显示资料与图片来源。
- `app/components/wiki/WikiDetail.vue`：组合档案速查型详情页。
- `scripts/sync-wiki-icons.mjs`：从已记录的来源下载图标到本地。
- `scripts/validate-wiki-data.mjs`：校验字段、引用、图片和四格配方。
- `素材文件/物品图标/来源清单.json`：图片文件与来源记录。

import { describe, expect, it } from 'vitest'
import { wikiEntries } from '../../app/data/wiki'

describe('wiki data', () => {
  it('contains the first complete core batch', () => {
    expect(wikiEntries.length).toBeGreaterThanOrEqual(120)
    expect(wikiEntries.filter(item => item.category === '料理')).toHaveLength(30)
  })

  it('has valid crafting or acquisition data', () => {
    for (const item of wikiEntries) {
      expect(item.sources.length).toBeGreaterThan(0)
      expect(item.image.sourceUrl).toMatch(/^https:\/\//)
      expect(item.acquisition.length).toBeGreaterThan(0)
      if (item.crafting?.craftable) {
        expect(item.crafting.ingredients.length).toBeGreaterThan(0)
        expect(item.crafting.station.length).toBeGreaterThan(0)
      }
    }
  })

  it('uses exactly four slots for every dish example', () => {
    for (const dish of wikiEntries.filter(item => item.category === '料理')) {
      expect(dish.dish).toBeDefined()
      for (const example of dish.dish!.examples) {
        expect(example.ingredients).toHaveLength(4)
      }
    }
  })
})
