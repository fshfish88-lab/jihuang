# 火堆边百科 MVP Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 构建并发布一个可搜索、可筛选、可保存主线进度的《饥荒联机版》新手攻略静态网站。

**Architecture:** 使用 Nuxt 3 静态生成页面，Nuxt Content v3 管理 Markdown 攻略正文与 Front Matter，Pinia 管理浏览器端进度，Fuse.js 建立中文别名搜索。GitHub Actions 在 `main` 分支推送后生成 `.output/public` 并发布到 GitHub Pages。

**Tech Stack:** Nuxt 3、Nuxt Content v3、Vue 3、TypeScript、Pinia、Fuse.js、Vitest、Playwright、GitHub Actions。

---

## 文件结构

```text
app/
  assets/styles/       全局设计令牌、排版、纸张纹理、组件样式
  components/          导航、搜索、卡片、筛选、进度和内容辅助组件
  composables/         搜索索引和本地进度逻辑
  layouts/             默认网站外壳
  pages/               首页、栏目列表、动态详情和工具页
  stores/              Pinia 主线进度状态
content/               5 入门、5 角色、5 Boss、3 路线、20 百科 Markdown
data/                  搜索别名、路线节点、外部资料
public/                本地字体、官方截图优化副本、纹理
scripts/               内容校验、静态成品导出
tests/                 Vitest 单元测试与 Playwright 页面测试
成品文件/github-pages/  本地导出的可部署静态站
过程文件/              需求、设计规范、实施计划、验证报告
素材文件/              原始官方截图、字体许可证、素材来源
```
