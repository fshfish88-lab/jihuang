# 火堆边百科 MVP 设计规范

## 1. 项目目标

“火堆边百科”是面向《饥荒联机版》新手玩家的非官方、非商业攻略站。首版不追求条目数量，而要先解决四个问题：

1. 我现在处于什么阶段？
2. 我接下来应该做什么？
3. 我需要准备哪些东西？
4. 完成后会解锁什么内容？

首版成功标准：用户能从首页在三次点击内进入任意核心攻略，能搜索常见名称或俗称，能完成角色/Boss 筛选，并能保存世界主线进度。

## 2. 首版范围

### 内容

- 5 篇萌新入门：第一天、第一周、建家选址、第一个冬季、常见误区。
- 5 个代表角色：威尔逊、温蒂、沃尔夫冈、薇格弗德、WX-78。
- 5 个代表 Boss：独眼巨鹿、熊獾、蜂后、克劳斯、远古守护者。
- 3 条世界路线：基础生存、洞穴与遗迹、月岛与天体。
- 20 个高频百科速查条目，覆盖物品、食物、建筑和生物。

### 功能

- 中文名称、英文名、玩家俗称与标签的模糊搜索。
- 角色与 Boss 分类筛选。
- 世界路线节点打勾、完成率计算、本地保存、一键重置。
- 内容四向关联：角色、Boss、主线、百科互相跳转。
- 响应式导航、键盘可用、减少动态效果支持。
- 唯一页面标题、摘要、规范链接和静态生成。

### 不在首版范围

- 用户系统、云端同步、评论、后台 CMS。
- 完整 100+ 百科、烹饪计算器、物品对比器、收藏系统。
- 商业化、广告或付费内容。

## 3. 技术方案

采用 Nuxt 3、Nuxt Content v3、Vue 3、TypeScript、Pinia、Fuse.js 与原生 CSS。

- Nuxt 负责路由、SEO、静态生成与 GitHub Pages 基础路径。
- Nuxt Content 读取 Markdown 正文和 Front Matter。
- Pinia 管理主线进度、筛选和搜索界面状态。
- Fuse.js 根据标题、英文名、别名、标签和摘要建立浏览器端搜索索引。
- LocalStorage 保存主线完成状态，不收集个人数据。
- GitHub Actions 执行安装、测试、静态生成并发布 `.output/public`。

攻略正文放在 `content/`，筛选、难度、别名、关联关系放在 Front Matter 与 `data/`。内容列表页必须显式链接所有详情页，使 Nuxt 的预渲染爬虫能够生成完整静态路由。

## 4. 页面结构

### 首页

1. 手账式首屏与全局搜索。
2. 四个核心入口。
3. “你现在在哪一步”生存时间线。
4. 五名角色速览。
5. 五个 Boss 推荐挑战顺序。
6. 三条世界路线与本地完成率。
7. 高频百科速查。
8. 最近更新、官方资料外链与非官方声明。

### 列表页

`/beginner`、`/characters`、`/bosses`、`/progression`、`/wiki` 使用统一档案卡片体系。角色/Boss 列表提供可清除筛选与“无结果”状态。

### 详情页

统一显示：

- 一句话结论、版本与更新时间。
- 当前目标、准备内容、按序步骤或战斗阶段。
- 新手提示、危险提醒、常见失败原因。
- 前置条件、完成标志、下一步。
- 相关角色、Boss、主线和百科链接。

### 工具页

`/tools/progression-checklist` 展示路线节点、完成率、下一步推荐与重置操作。所有进度只存于当前浏览器。

## 5. 视觉系统

已确认方向：B2“更贴近《饥荒》的荒野旅行手账”。

### 四个定位问题

- 叙事角色：首页是翻开求生笔记的入口；列表页是档案索引；详情页是可执行手册；进度页是铅笔任务清单。
- 观看距离：优先适配手机 10–30 cm 阅读，同时保证桌面端知识库效率。
- 视觉温度：冷峻荒野中的手写温度；不做可爱卡通，也不做现代 SaaS。
- 容量检查：详情页正文宽度控制在 72 个中文字符以内；辅助信息在桌面端进入侧栏，移动端折叠到正文后。

### 设计决策

- 颜色：骨白旧纸 `#E3D8B6`、灰黄纸 `#CBBF9B`、炭黑 `#171714`、暗血红 `#7B271D`、枯草绿 `#5B6042`、灰烬褐 `#5B564B`。
- 字体：标题使用开源手写展示字体；正文使用开源中文楷体/宋体组合；数值使用等宽字体。字体文件本地托管并保留许可证。
- 间距：以 4px 为基础单位，常用 8/12/16/24/32/48/64。
- 圆角：纸张和卡片以 0–8px 小圆角为主；搜索框和标签可使用胶囊形；不用统一大圆角。
- 阴影：只模拟纸层和压印，采用硬边 2–6px 阴影；不使用发光或玻璃拟态。
- 动效：120–220ms 的轻微位移、旋转和铅笔划线；尊重 `prefers-reduced-motion`。
- 图形：撕纸边缘、铅笔线、印章、编号和档案标签；不使用 Emoji 充当图标。

## 6. 素材与版权

- 本站标识使用自制“火堆边百科”文字标，不使用《饥荒》官方 Logo。
- 游戏截图优先取自 Klei 官方游戏媒体页或官方 Press Kit，并保存到本地素材目录；不热链。
- 攻略数据以 Klei 官方更新信息和 `dontstarve.wiki.gg` 条目交叉核对，正文自行编写，不复制其他攻略全文。
- 页脚明确说明：本站为玩家制作的非官方、非商业资料站，与 Klei Entertainment 无官方关联；游戏名称、角色、图片和相关素材版权归权利人所有。
- 页脚提供《饥荒联机版》官方页面、Steam 页面、Klei 玩家创作指南与中文 Wiki 外链。

## 7. 可访问性和状态

- 正文与背景对比度达到 WCAG AA 目标。
- 所有交互元素可使用键盘，焦点样式清晰，触控目标不小于 44px。
- 图片有描述性替代文本；危险级别同时显示文字，不仅依靠颜色。
- 搜索提供初始提示、结果、无结果和清除状态。
- 本地存储不可用时，进度仍可在当前页面操作，并显示“未保存”提示。
- 动画在减少动态效果模式下关闭。

## 8. 验证

- 单元测试：别名搜索、筛选组合、进度计算与本地存储容错。
- 页面测试：首页核心链接、搜索打开结果、筛选无结果、任务勾选与刷新保留。
- 构建测试：`npm run generate` 成功，所有核心路由生成 HTML。
- 视觉测试：桌面 1440×900、平板 768×1024、手机 390×844。
- 发布复测：GitHub Pages 返回 200，CSS/字体/图片无 404，刷新详情页不丢失。
