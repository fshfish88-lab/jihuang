# 《火堆边百科》饥荒联机版新手攻略网站可执行方案

> 项目定位：面向《饥荒联机版》新手玩家，提供“萌新入门、角色攻略、Boss 攻略、世界主线、百科查询和实用工具”六类内容。
>
> 核心目标：让玩家随时知道自己当前处于什么阶段、接下来应该做什么、需要准备什么、完成后会解锁什么。

---

# 1. 项目基本信息

## 1.1 网站名称

推荐名称：

**火堆边百科｜饥荒联机版新手生存手册**

备选名称：

- 恒常生存手册
- 永恒领域档案馆
- 萌新不饿指南
- 查理的生存笔记

## 1.2 网站标语

> 从第一团火开始，活过每一个季节。

## 1.3 目标用户

- 第一次接触《饥荒联机版》的玩家
- 已经会基础生存，但不知道下一步做什么的玩家
- 想学习特定角色玩法的玩家
- 想挑战 Boss，但不知道准备流程的玩家
- 想了解月岛、遗迹、暗影、裂隙等世界进程的玩家

## 1.4 项目差异化

本项目不以“条目最多”为核心，而是强调：

1. 按玩家成长顺序组织内容；
2. 所有攻略都标注前置条件和后续内容；
3. 角色、Boss、主线、物品互相跳转；
4. 重点解释“为什么这样做”，而不是只罗列数据；
5. 为新手提供最低配置、推荐配置和高效配置三档方案。

# 4.1 萌新入门

## 页面目标

回答“我刚进入世界，现在应该做什么”。

## 建议文章

- 游戏版本与模式区别
- 创建世界时如何设置
- 新手是否需要安装模组
- 第一天应该做什么
- 第一个晚上如何生存
- 如何快速探索地图
- 建家位置怎么选
- 第一周发展路线
- 第一个冬季准备清单
- 死亡后如何复活
- 常见新手误区

## 新手时间线

```text
第1天：收集草、树枝、燧石，制作工具和火把
第2—5天：探索地图，寻找关键资源区
第6—10天：建造基础基地，稳定食物来源
第11—20天：准备冬季装备、食物和 Boss 应对方案
第21天以后：洞穴、遗迹、航海、Boss 和世界主线
```

## 验收标准

- 每篇文章必须有“当前目标、准备物品、操作步骤、常见错误、下一步”五部分；
- 所有操作步骤按顺序编号；
- 每篇文章至少链接 3 个百科条目；
- 每篇文章至少链接 1 个后续攻略。

# 4.4 世界主线

## 核心原则

《饥荒联机版》没有传统意义上唯一、完全线性的任务主线。因此本网站统一采用：

- 世界主线
- 世界进程
- 终局路线
- 当前版本进度

避免使用“唯一通关路线”一类表述。

## 主线总览图

```text
基础生存
   ↓
稳定基地与四季循环
   ↓
洞穴、遗迹与航海
   ↓
┌──────────────┬──────────────┐
│ 暗影与遗迹路线 │ 月亮与海洋路线 │
└──────────────┴──────────────┘
          ↓
      裂隙与终局内容
```

## 路线一：基础生存线

```text
创建世界
→ 收集基础材料
→ 制作工具和火源
→ 探索地图
→ 选择基地位置
→ 建造科学机器
→ 建造炼金引擎
→ 建立食物循环
→ 准备第一个冬季
→ 应对季节Boss
→ 建立稳定基地
```

### 每个节点应包含

- 推荐阶段；
- 前置条件；
- 必备物品；
- 具体操作；
- 常见错误；
- 完成标志；
- 下一节点。

## 路线二：洞穴与遗迹线

# 4.6 生存工具

## 第一阶段工具

1. 烹饪计算器
2. 角色选择助手
3. 世界主线任务清单
4. 物品对比工具

## 烹饪计算器功能

输入四个食材后显示：

- 可能生成的料理；
- 食谱优先级；
- 属性恢复量；
- 食材浪费提示；
- 更便宜的替代方案；
- 是否适合新手；
- 保质期与使用场景。

## 角色选择助手问题

```text
你主要单人还是多人？
你偏向战斗、建造、采集还是辅助？
你能否接受明显缺点？
你是否愿意学习复杂机制？
你是否经常因为战斗死亡？
```

最终输出：

- 推荐角色 2—3 个；
- 推荐原因；
- 不推荐角色；
- 建议先阅读的角色攻略。

## 主线任务清单

支持：

- 节点打勾；
- 自动计算完成率；
- 保存到本地浏览器；
- 一键重置；
- 显示下一步推荐节点。

# 17. 最终项目定位总结

**火堆边百科**不是单纯的数据查询网站，而是一套围绕玩家成长路径设计的新手学习系统。

网站需要始终回答四个问题：

1. 我现在处于什么阶段？
2. 我接下来应该做什么？
3. 我需要准备哪些东西？
4. 完成后会解锁什么内容？

只要所有页面都围绕这四个问题设计，角色攻略、Boss 攻略、世界主线和百科资料就能形成一套完整、易懂、可持续扩展的网站体系。
